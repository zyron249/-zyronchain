ZyronChain Windows Miner candidate

1. Extract the ZIP.
2. Open the extracted ZyronMiner-windows-x64 folder.
3. Double-click ZyronMiner.cmd.

No Git, npm, Node.js, or PowerShell setup is required by the packaged runtime.

IMPORTANT: Public mining is still activation-gated. Until the canonical network profile is activated, the launcher intentionally exits without creating wallet custody. Package availability does not mean public mining is live.
