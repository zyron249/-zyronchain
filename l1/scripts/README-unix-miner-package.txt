ZyronChain Linux/macOS Miner candidate

1. Extract the .tar.gz archive.
2. Open a terminal in the extracted ZyronMiner-* folder.
3. Run: ./ZyronMiner

The package includes its own Node.js runtime and production dependencies. Git, npm, and a system Node.js installation are not required.

IMPORTANT: Public mining is still activation-gated. Until the canonical network profile is explicitly activated, the launcher intentionally exits before creating or modifying wallet custody. Package availability does not mean public mining is live.
