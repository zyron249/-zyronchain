Staking

Staking

Not supported by the protocol The ZyronChain protocol has no staking or delegation today. Validators are admitted by a signed validator-set update approved by existing validators, not by locking ZYN.

  • No block rewards exist: supply is fixed and nothing is minted.
  • Any future staking would need a protocol upgrade, an independent audit and a governance decision, and could only pay from already existing ZYN.

Security

Security

  • Never share your recovery phrase. Nobody from ZyronChain will ask for it, in Telegram or anywhere else.
  • This Hub stores nothing in your browser and holds no keys.
  • This page talks only to the game service and the wallet testnet. Web sign-in is read-only and uses a one-time code sent to you by @ZyronNodeBot.
  • There is no token sale. Anyone offering ZYN for money is not ZyronChain.
  • Linking a wallet to the game only proves you hold the key; it never moves funds.
