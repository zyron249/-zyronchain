Privacy

Privacy policy

ZyronChain’s website is a documentation and local onboarding surface. It is designed to collect as little as possible.

What this site does not do

  • No analytics cookies. This site does not set analytics, advertising or tracking cookies.
  • No website account. There is no signup, login or user profile on zyronchain.com.
  • No key collection. The site never asks for, receives or stores private keys, seed phrases, wallet passwords or encrypted keystores.
  • No remote wallet API. Browser scripts stay offline-only (connect-src 'none'). Wallet and validator tooling generate local scripts; secrets stay on your machine.

What may be processed elsewhere

If you visit linked third-party services (GitHub, X/Twitter, Telegram), those services apply their own privacy policies. ZyronChain does not control those properties.

Hosting and server logs

Whoever hosts the static website may retain ordinary web server logs (for example IP address, user agent and requested path) as part of normal operations. This project does not run website-side analytics on top of those logs.
