Verify headers in this browser

This page asks the public open-testnet gateway for block headers and checks them here: hash chaining, proposer signatures, and a quorum of distinct validator signatures. The launch profile on that network requires at least 4 distinct validators. Nothing on this page is a price, a balance, or a mainnet claim.

Checks

Passed means this browser checked it. Failed means a check did not hold. "Not available on this network" means the gateway does not serve the data, so the result is not invented.

    What this page does not do

    • It does not produce blocks, sign messages, or hold a validator key.
    • A matching signature means a quorum of the served genesis validator set signed that header. It does not by itself prove an independent operator set.
    • The repository snapshot pin is compared with the served genesis hash. A mismatch is reported. It is not rewritten to match.
    • State inclusion proofs, non-membership proofs, and validator-set transition proofs are listed when the gateway does not serve them.

    Gateway: https://zyron-open-testnet.onrender.com. The free host can sleep. This page retries with backoff and says so.
