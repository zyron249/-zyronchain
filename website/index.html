Technology

Security boundaries are part of the protocol.

01

Deterministic execution

Exact integer accounting, replayable state transitions and canonical transaction/block identities.

02

Authenticated state

State-v2 uses content-addressed authenticated state with checkpoint, pruning and corruption-recovery controls.

03

Quorum finality

Finality requires a strictly greater-than-two-thirds validator quorum with certified proposer-failure view changes.

04

Fail-closed upgrades

Protocol upgrades, rollback and validator-set changes are delayed and quorum authorized.

05

Native P2P

Noise-authenticated libp2p sessions bind PeerId, node identity, chain ID and genesis before sync or consensus traffic.

06

Founder-exit discipline

Succession, operator challenge and external evidence gates prevent fake decentralization claims.
