Protocol

A Layer-1 built around explicit trust boundaries.

ZyronChain treats consensus, persistence, upgrades, networking and operator independence as separate security boundaries. Each boundary has deterministic tests and fail-closed behavior.

Evidence before claims.

Readiness is not inferred from a green build alone. ZyronChain separates synthetic regression evidence from real-world operational proof and keeps activation closed when external evidence is missing.

Developers

Clone. Build. Verify.

The canonical TypeScript L1 is developed in the public repository. Node.js 22+ is required; Node.js 24 is the preferred test runtime.

quick-start.sh 
# Clone the canonical repository
git clone https://github.com/zyron249/-zyronchain.git
cd -zyronchain/l1

# Install, build and run the test suite
npm ci
npm run build
npm test

Explorer

Designed for observable state.
