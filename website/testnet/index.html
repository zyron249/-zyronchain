Wallet testnet

Look up an address on the no-value wallet testnet, or paste a signed transfer from the phone wallet. Chain id zyron-wallet-testnet-1.

Test ZYN has no value. Balances and nonces stay across a free-host sleep when durable storage is on. They can still reset if durable storage is off, or if this network is deliberately reset. The genesis hash can change when the process starts, because block production needs a recent genesis time. That hash change does not by itself wipe a durable balance. Balances and transactions above the gateway's durableHeight can roll back on a gateway cold start. Test ZYN cannot be bought or sold.

This page never asks for a recovery phrase, a password or a private key. Keys stay in the phone wallet. Only a signed transfer leaves that device.

Contacting the wallet testnet. A sleeping free host can take up to 2 minutes to wake.
